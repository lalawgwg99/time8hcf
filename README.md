# TIME 8 · 簡約工時記錄工具

基於 Apple 原生設計理念的純前端工時追蹤 Web App (PWA)。所有資料永久保存於使用者的瀏覽器 `localStorage`，兼顧極速啟動、離線可用與隱私保護。

---

## 核心設計規範

- **視覺語言**：SwiftUI Inset Grouped 清爽卡片結構、SF Pro 系統字體、高對比留白與克制色彩。
- **主題風格**：4 款 Apple 系統調色（經典素白、黑曜夜色、竹影青綠、暮光晨紫）。
- **觸覺與回饋**：細膩震動、水滴反饋音、滑動防誤觸機制。

---

## 主要功能

### 1. 工時記錄與光環進度
- **上班打卡**：輕點「上班」即時啟動計時。
- **下班滑動打卡**：向右滑動確認收工，防止誤觸。
- **中央工時光環**：即時顯示今日工時進度，輕點中央數字可在「今日累計」與「倒數剩餘」模式之間自由切換。
- **四角快捷工具**：
  - 左上：即時氣溫、降雨機率與 12 小時逐時天氣預報。
  - 右上：今日專注任務、核心待辦清單與隨手靈感便籤。
  - 左下：電子木魚（紓解壓力、自訂提示詞與定速 BPM 敲擊）。
  - 右下：下班時間小圓標（自動比對歷史班次間隔時長）。

### 2. 門市速查與跨店運費（洞察分頁）
- **全省門市速查**：完整收錄全台 62 家門市分機、地址、店長、處長、課長與助理窗口，支援 0 毫秒即時搜尋與一鍵撥號。
- **跨店外送運費**：59 家門市跨區外送費用對照與智慧試算。
- **家電 MD 分機表**：北中南區家電商品部窗口電話速查。

### 3. 勞基法健康守護防線
- **第 35 條（連續工作預警）**：連續工作達 230 分鐘主動提醒休息，避免超時。
- **第 34 條（11 小時跨日休息守護）**：上班打卡自動比對與前次下班間隔是否達 11 小時，守護充足睡眠。

### 4. 晨曦啟程 · 每日箴言
- 每日首度打卡上班時，自動呈現啟發性之每日箴言與工作指引。

### 5. 工時夥伴展台
- 依據每日工時累積成長進度（7 段光環結晶與 8 款外觀圖鑑）。

---

## 技術架構

- **前端技術**：純原生 HTML5 / CSS3 / Vanilla JavaScript（零外部重型框架依賴）。
- **圖示與字型**：Apple 原生 SVG 向量圖標、SF Pro Display / Text 系統字體。
- **PWA 支援**：支援 iOS Safari「加入主畫面」全螢幕運行、Service Worker 快取。
- **資料儲存**：全本地端 `localStorage` 離線儲存，100% 隱私無伺服器上傳。

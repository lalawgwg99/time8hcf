# Time Tracker (工時紀錄 & AI 職場助手)

這是一個專為現代職場設計的工時紀錄 Web App，特別針對「賣場/銷售人員」優化。除了基本的打卡功能外，更強調「準時下班」與「工作生活平衡」。

## ✨ 特色功能

### 1. 智慧工時預測

- 自動計算今日工時，即時顯示 **「預計下班時間」**。
- **8 小時進度條**：視覺化呈現工時進度，滿 8 小時自動變色提醒。

### 2. 🤖 AI 下班日報 (Smart Exit)

- **專屬角色**：預設為 **「家電賣場/銷售人員」** 角色。
- **一鍵生成**：串接 AI 模型，根據打卡時間自動撰寫專業日報。
- **自動潤飾**：自動補充「庫存盤點」、「客情維繫」等專業術語，讓日報看起來充實又專業。

### 3. ❤ 職場健康度 (WLB Score)

- **Gamification**：將「準時下班」與「適度休息」遊戲化。
- **評級系統**：從「S級 自由人」到「D級 地縛靈」，即時給予主要評分與建議。

### 4. 🍻 下班生活提案

- **暖心互動**：系統會根據您「預計幾點能走」，提供隨機的生活建議。
- **時段情境**：包含逛書店、買菜、鹹酥雞、泡熱水澡等在地化建議。

### 5. 📅 穩定休息提醒

- 整合 **.ics 行事曆檔案**，可直接將休息提醒加入手機行事曆。
- 解決網頁在手機鎖屏後無法發出聲音通知的問題。

## 技術架構

- **Frontend**: HTML5, Vanilla JS
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Font Awesome
- **AI Integration**: NVIDIA API (DeepSeek-R1) via Proxy
- **Audio**: Tone.js

## 如何使用

1. 直接開啟 `index.html` 即可使用。
2. 支援 iOS/Android 加入主畫面 (PWA capable)。

## 隱私說明

本應用程式為純前端運作，打卡資料僅儲存於瀏覽器 `localStorage`，不會上傳至任何伺服器。AI 功能僅傳送打卡時間與任務文字片段進行處理。
